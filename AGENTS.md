# arch-viewer

Interactive architecture diagrams of a codebase. See `README.md` for the overview.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues (rmacdonaldsmith/arch-viewer), managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
